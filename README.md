## 🇮🇩 Bahasa Indonesia

Browser Android ringan berbasis WebView, dibuat oleh Herdian Herman.

### Fitur
- Multi-tab, tekan lama tautan untuk membuka di tab baru
- Dashboard dan riwayat
- Pemblokir iklan
- Jendela privat
- Picture-in-Picture dengan tombol putar/jeda
- Kunci aplikasi opsional (PIN / sidik jari)

3. Buka file APK, lalu pasang.

## 🇬🇧 English

A lightweight Android browser built on WebView, made by Herdian Herman.

### Features
- Multiple tabs, long-press a link to open it in a new tab
- Dashboard and history
- Ad blocker
- Private window
- Picture-in-Picture with a play/pause button
- Optional app lock (PIN / fingerprint)

### Download
Get the latest APK from [Releases](https://github.com/Omenose/mybrowser-release/releases/latest).

### Install
1. Download the APK file from the Releases page.
2. Allow "install from unknown sources" for the app you use to open the file.
3. Open the APK and install it.

### Verify (optional)
Signing certificate fingerprint (SHA-256):

`53d2a5f782c8b398369df1e1d146ef22998e1e8cae48c0ddfb73d417a56bb67d`
